## 🚀 Продуктовые кейсы и MVP-прототипы

### 1. RunStart Buddy — адаптивная фитнес-платформа для бегунов
Цифровой продукт для безопасной подготовки к забегам: от первых 5 км до марафона. Решает проблему травматизма новичков (79%) и потери мотивации за счёт адаптивных планов тренировок на базе ИИ.

* **Моя роль:** исследование рынка и конкурентов (Strava, Nike Run Club), формулирование гипотез, декомпозиция функционала, написание User Stories и Acceptance Criteria, сборка интерактивного прототипа и презентация бизнес-модели.
* **Инструменты:** Lovable (AI), Miro, Figma, продуктовая аналитика.
* 🔗 **[Открыть интерактивный MVP-прототип](https://easyrunstart.lovable.app/)**
